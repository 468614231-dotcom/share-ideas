## 1. 设计皮肤系统（token 体系）

主题不再是"换色"，而是整套设计 token 联动。修改皮肤 = 修改对应 `body.theme-xxx` 块的变量，组件样式全部引用 token，自动跟随。

| token | 作用 |
|---|---|
| `--bg / --bg-2` | 页面底色 / 面板底色 |
| `--primary / --accent / --highlight / --danger` | 强调色（≤3 + 1 语义色） |
| `--text / --dim` | 正文深色 / 次级中灰 |
| `--line / --line-dim` | 边框线（主色低透明度） |
| `--radius-sm / --radius-md / --radius-lg` | 圆角体系（标签/卡片/大块） |
| `--shadow-1 / --shadow-2` | 常态阴影 / 悬浮阴影（柔和多层） |
| `--card-glass / --card-blur` | 毛玻璃不透明度 / 模糊强度 |
| `--font-display` | 大标题字体（可切衬线） |
| `--bg-pat` | 背景纹样（细网格等，默认 none） |

原则：**组件样式永远写 token，不写死数值**；新增皮肤 = 新增一组 `body.theme-xxx` 变量块 + 注册到 JS `themes` 数组。

## 2. 三套皮肤色板与设计语言

设计基调：**白/浅灰底、深色文字、无黑色底、无辉光**。每套皮肤有独立的圆角/阴影/字体/玻璃语言。

### 皮肤 A · 科技蓝（tech，默认）—— 现代圆润

| 维度 | 值 |
|---|---|
| 颜色 | primary 蓝 `#2563EB` / accent 青绿 `#0E9F8A` / highlight 琥珀 `#D97706`；底 `#FFFFFF`/`#F4F7FB` |
| 圆角 | 12 / 18 / 28px（大圆角） |
| 阴影 | 蓝调柔和：`0 18px 44px -12px rgba(37,99,235,.16)` |
| 玻璃 | `rgba(255,255,255,.62)` + blur 18px（强玻璃） |
| 字体 | 现代无衬线 |
| 调性 | 轻盈、明亮、有科技感的产品发布语言 |

### 皮肤 B · 咨询金（consult）—— 克制优雅

| 维度 | 值 |
|---|---|
| 颜色 | primary 金 `#B08A2E` / accent 藏蓝 `#2F5B96` / highlight 深金棕 `#8C6D1F`；底 `#FBFAF7`/`#F3F0E8` |
| 圆角 | 4 / 8 / 14px（细圆角） |
| 阴影 | 中性收敛：`0 14px 36px -14px rgba(32,36,44,.12)` |
| 玻璃 | `rgba(255,255,255,.82)` + blur 10px（轻玻璃） |
| 字体 | 标题衬线（Songti SC / STSong / SimSun），正文无衬线 |
| 调性 | 大留白、细线、经典咨询报告质感（麦肯锡/BCG 风格变体） |

### 皮肤 C · 墨绿金（finance）—— 几何精确

| 维度 | 值 |
|---|---|
| 颜色 | primary 墨绿 `#2F7D5C` / accent 金 `#A17E24` / highlight 银灰 `#3F4A44`；底 `#F6F8F6`/`#EDF2EE` |
| 圆角 | 2 / 4 / 6px（近直角） |
| 阴影 | 紧凑中性：`0 12px 30px -14px rgba(28,36,32,.14)` |
| 玻璃 | `rgba(255,255,255,.92)` + blur 6px（近乎实底） |
| 字体 | 无衬线 + 等宽数字 |
| 纹样 | 44px 细网格底纹（`--bg-pat`） |
| 调性 | 严谨、数据密度高、金融年报语言；绿=正向、红=负值的语义沟通 |

## 3. 视觉锚点组件规范（每页至少一个）

年轻人审美的核心：**图形记忆点**。下列组件用于打破纯文字页：

| 组件 | 触发动画 | 数据绑定 |
|---|---|---|
| 面积图 `.chart-area` | 描线生长 + 渐变填充淡入 | SVG path 手绘（模板有示例曲线） |
| 环形进度 `.ring` | 圆环生长 | style=`--pct:72`；中心数字 `data-count` |
| 大数字 `.num` | 数字滚动 | `data-count="105" data-suffix="%" data-prefix="¥" data-dec="1"` |
| 图标要点行 `.icon-row` | 卡片浮起 | 内置三个示例 SVG（增长/目标/对勾） |
| 描边年份封面 `.cover[data-year]` | 静态锚点 | `data-year="2026"` 大号描边字 |
| 时间线 `.steps` | 节点+连线 | 静态 |

规则：一页 ≥ 1 个锚点组件；趋势用面积图、占比用环形、并列用图标行、里程碑用时间线。

## 4. 主题选择指引

| 用户场景关键词 | 推荐皮肤 |
|---|---|
| 发布会、技术、增长、互联网、产品周报 | 科技蓝 tech |
| 方案评审、咨询、战略、高管、管理层述职 | 咨询金 consult |
| 财报、年报、投资、结题、监管、严谨 | 墨绿金 finance |
| 拿不定 | 默认科技蓝，交付时告知按 T 可切换对比 |

改皮肤 = 改 `<body class="theme-xxx">` 一处；封面版式：`cover`（居中）→ 加 `left`（左对齐）→ 加 `split`（左标题右结论卡）。

## 5. 总分总结构与页面类型骨架

**硬性结构**：总起（1–2 页）→ 分述（3–5 页）→ 总结（1 页）。

| 场景 | 总起 | 分述 | 总结 |
|---|---|---|---|
| 述职/OKR | 封面、业绩概览 | 核心指标、重点项目、复盘与改进 | 下一步计划 |
| 周报/月报 | 封面、本周概览 | 数据指标、关键动作、风险求助 | 下周计划 |
| 项目汇报 | 封面、目标与现状 | 关键动作时间线、方案对比、风险应对 | 下一步 |
| 产品发布 | 封面、卖点总览 | 数据背书、用户反馈、上线计划 | 结尾 Q&A |
| 方案评审 | 封面、背景与问题 | 两套方案对比、推荐依据、风险回退 | 结论与决策项 |
| 金融年报 | 封面、业绩摘要 | 财务指标、分部表现、风险展望 | 结语 |

页内结构：kicker → h1 → lead（一句话结论）→ 组件群（2–3 组，含锚点组件）→ 口径小字。

## 6. 标题层级规范

| 层级 | 元素 | 字号 | 颜色 | 用途 |
|---|---|---|---|---|
| 0 页签 | `.kicker` | 13px 等宽 + 0.3em 字距 | 辅色（`//` 为主色） | 页码与英文小节名 |
| 1 页标题 | `h1` | clamp(30–52px) 800 + 主色下划线 | 正文深色（衬线皮肤用衬线） | 每页唯一大标题 |
| 2 分节 | `h2` | clamp(20–27px) 700 | 主色 | 页内大分区 |
| 3 要点 | `h3` | clamp(16–19px) 600 | 正文深色 | 卡片/列表标题 |
| 正文 | `p / li` | 14–16px 1.8 行高 | 中灰 | 说明文字 |

规则：一页一个 `h1`；封面放大到 clamp(44–96px)；不跳级；正文禁止加粗冒充标题。

## 7. 组件用法（最小示例）

```html
<!-- 大数字（自动滚动） -->
<div class="stat"><span class="num" data-count="105" data-suffix="%">0%</span><span class="label">目标达成率</span></div>

<!-- 环形进度 -->
<div class="ring" style="--pct:72">
  <svg viewBox="0 0 120 120"><circle class="ring-track" cx="60" cy="60" r="52"/><circle class="ring-bar" cx="60" cy="60" r="52"/></svg>
  <div class="ring-num"><b data-count="72" data-suffix="%">0%</b><span>留存</span></div>
</div>

<!-- 图标要点行 -->
<div class="card icon-row">
  <div class="ico"><svg viewBox="0 0 24 24" fill="none" stroke-width="2.4" stroke-linecap="round" stroke-linejoin="round"><polyline points="5,13 10,18 19,7"/></svg></div>
  <div><h3>标题</h3><p>一句话说明</p></div>
</div>

<!-- 封面三选一 -->
<section class="slide cover" data-year="2026">…居中…</section>
<section class="slide cover left" data-year="2026">…左对齐…</section>
<section class="slide cover split" data-year="2026">…左标题右结论卡…</section>
```

复用规则：数量 ≥ 2 同类元素一律用组件；新增组件需在模板内验证渲染与动画。

## 8. 简洁度与精简检查清单

**元素精简**：页面只含 顶栏（品牌/皮肤/页码）、进度条、圆点、◀▶、备注面板；**不要**添加页脚描述、霓虹辉光、闪烁动效、多余装饰。

**内容（逐页过）**：
- [ ] 全页只有一个 h1、一个主题
- [ ] 要点 ≤ 5 条，单条 ≤ 22 字
- [ ] 无口头语/铺垫/重复解释，每句只留主谓宾 + 一个数据
- [ ] 数字优先：有数据不用"显著/大幅"类形容词
- [ ] 组件 ≤ 3 组，留白 ≥ 内容 40%
- [ ] 每页至少 1 个视觉锚点（图形组件）
- [ ] 页脚口径小字（如适用）
- [ ] 总页数 5–8，超出则合并同类页
