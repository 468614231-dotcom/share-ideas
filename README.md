# cyberpunk-presentation · Pro Deck

专业 HTML 演讲汇报页生成器（单文件，零依赖，离线可用）。

把用户内容转成一份可直接打开、可上台演示的 HTML 汇报页：浅色专业底、三套差异化设计皮肤、≤3 强调色、视觉锚点组件、总分总结构、全套演示交互。

## 三套设计皮肤（按 T 键实时切换）

| 皮肤 | body 类 | 设计语言 | 色板（primary / accent / highlight） | 适用场景 |
|---|---|---|---|---|
| **科技蓝**（默认） | `theme-tech` | 现代圆润：大圆角 + 毛玻璃 + 蓝调阴影 | 蓝 #2563EB / 青绿 #0E9F8A / 琥珀 #D97706 | 产品发布、技术汇报、增长路演 |
| **咨询金** | `theme-consult` | 克制优雅：细线 + 衬线标题 + 大留白 | 金 #B08A2E / 藏蓝 #2F5B96 / 深金棕 #8C6D1F | 方案评审、商业分析、高管述职 |
| **墨绿金** | `theme-finance` | 几何精确：直角 + 细网格 + 数据密度 | 墨绿 #2F7D5C / 金 #A17E24 / 银灰 #3F4A44 | 年报、财报、投资汇报 |

皮肤不是"换色"，而是整套设计 token 联动（圆角 / 阴影 / 标题字体 / 毛玻璃 / 底纹）。

## 特性

- **浅色底、无黑色、无辉光**；每主题强调色 ≤ 3 种（+1 语义色 `--danger` 仅用于风险）
- **总分总结构**：封面总起 → 主体分述 → 收尾总结（5–8 页）
- **视觉锚点组件**：面积图（SVG 渐变描线）、环形进度、count-up 大数字、图标要点行、描边年份封面、时间线
- **动效质感**：滑动进场、数字滚动、卡片倾斜跟随（仅鼠标）、柱状/环形生长、打字机；全部尊重 `prefers-reduced-motion`
- **演示交互**：← → / 空格 / 滚轮 / 触屏 / 点击翻页、数字跳页、T 换皮肤、F 全屏、N 演讲备注、进度条、圆点导航

## 快速开始

1. 复制 `assets/template.html` 为输出文件（建议中文名，如 `述职报告.html`）
2. 选皮肤：改 `<body class="theme-xxx">`；换封面版式：`cover` 加 `left` 或 `split`
3. 按「总分总」骨架替换 `<section class="slide">` 内容
4. 浏览器打开即用

## 文件结构

```
cyberpunk-presentation/
├── SKILL.md                  # 技能说明（AI 使用入口）
├── assets/
│   └── template.html         # 可交互模板（三皮肤 + 全部组件示例）
└── references/
    ├── design.md             # 设计 token 体系、皮肤色板、页面骨架、检查清单
    └── interactions.md       # 交互清单、定制方法、常见问题
```

## 快捷键

`← →` 翻页 · `T` 皮肤切换 · `F` 全屏 · `N` 演讲备注（页面不显示提示，保持画面干净）
